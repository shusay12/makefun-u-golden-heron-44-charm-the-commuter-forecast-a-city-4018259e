One line of weather, 140 characters at most, for a city that does not exist —
name the place, give it weather, and make a bored commuter smile.

## Entry

> Snozzlewick: light drizzle of warm soup, 19°C; the 7:42 is ten minutes late, but the driver is singing — don't forget your spoon.

## Run

```sh
python3 main.py   # writes /output/entry.txt (129 chars, deterministic)
```

`main.py` uses only the Python 3.13 standard library and makes no network
calls. Two runs produce byte-identical output (see `run1/entry.txt` and
`run2/entry.txt`).
